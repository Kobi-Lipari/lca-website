How ties are broken

US Chess order. Each step counts only if the one before is still tied.

  1. Modified median: add your opponents' final scores, then drop the lowest (you scored over 50%), the highest (under 50%) or both (exactly 50%).
  2. Solkoff: the same sum, nothing dropped.
  3. Cumulative: add your running score after each round, so early wins count more.
  4. Opponents' cumulative: add up your opponents' cumulative scores.
  5. Most games with Black.

Byes, forfeits and unplayed games count as draws in an opponent's score and as zero in your own. Tiebreaks set the order and the trophies; tied players split cash equally.
