Rules of the menu

  1. The WS02 order never changes: to-dos, My LCA, the event line, Family, Membership card, the rooms by role, Log out.
  2. Every room row carries its count in words and is gated on the same flag as its route, so no menu holds a dead link.
  3. One label per destination, from nav.ts.
  4. The menu never holds a Workspace or Admin panel row.
Trade-off of Int-A

The page grows with every role: Chris’s six sections scroll about 3400px at 1440 wide, so sections must collapse and remember it per device, and the Today list must be ranked well or one role’s noise drowns the rest. Every room needs its own crumb and back control. The rooms share no sidebar, so a representative hopping between nine clubs goes club › region › club or uses the room’s own tabs. Workspace vanishing as a word means WS08’s and WS09’s chrome copy is renamed while the paths stay. In return it is exactly what K wrote: a member’s extra roles and their stuff live in My LCA, and nobody but an admin sees the admin panel.
