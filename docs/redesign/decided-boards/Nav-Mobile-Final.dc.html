Notes on this board
1App bar, 56px navy. Rook mark and "Louisiana Chess / Association"; tapping it goes home. The 44×44 bordered Search button opens /search, a real page, so Back works and the keyboard never fights a modal.
2Four tabs, words from nav.ts. Tournaments · Clubs · Log in · Menu, the same words as desktop. Labels always show: 20px icon over a 12px label, every tab the full 56px bar height.
3Current tab. Bold navy label plus a 3px top bar in gold-ink #866a1e and aria-current="page". Never colour alone. The bar never hides on scroll.
4To-do count on My LCA. Personal to-dos only: unpaid entries, an LCA membership ending within 30 days or expired, a US Chess membership ending before an entered event. Never volunteer queues or event-day items. Navy pill, "9+" cap, hidden at 0. Read as "My LCA, 2 things to do".
5Section name in the app bar. When the Menu tab is current (Scholastic, News, Membership, About pages), the section name shows in light gold #e6cf86 between the brand and Search.
6Menu sheet (M1). Opens from the Menu tab, which reads "Close". Six sections; the current one is expanded and marked "You are here" in #866a1e. Focus is trapped; Esc returns focus to the tab.
7Donate first, two taps. Donate · My LCA · Renew in the desktop order, right after the sections (signed out: Donate · Log in · Join LCA). Then role tools, then Facebook ↗ · Contact · Website help.
8Appearance and Hide. System / Light / Dark is a shortcut to the footer control. "Hide event bar until the next update" shows only in event mode and writes the same event:phase:round key as the bar's Hide button.
9In-flow banner (M4). A card under the app bar with role="status", never fixed, never over content. Once per state key per device, inserted only on page load, route change or near the top of the page. Dismiss stores the key; nothing runs on a timer.
10Docked event bar. M4's pill as a 56px full-width row inside the bottom stack, directly above the tabs. The row is one link to My board; the separate 44×44 × is "Hide until the next update". Live tokens in round states.
11One copy builder. Guardian and TD lines come from eventModeCopy.ts, the same source as the desktop strip. Full words only, never abbreviations. Buttons: "TD console" on bars, "Open TD console" on banners.
12"New" tag. If the reader has scrolled, the banner waits for the next page view. The bar gains a "New" tag and the dock's status node announces once, so nothing jumps (no layout shift).
13Check-in, light tint. The bar starts at check-in on day 1, in the light tint #fbf7e9 with a gold-ink rule; live tokens only once a round is posted. Event week is a card in My LCA and on Home, not a bar.
14Log in tab. The tab passes the current page as state.from, so logging in returns you to where you were. Reassurance above the form; "Create an account" and the browse-without-an-account line below.
15Chrome budget, iPhone SE. App bar, event bar and tab bar at 320 × 568. Labels drop to 11px under 360px; the words never change. Check on real phones at the pilot event.
16Tablet, 768–1023px. Hybrid header: Tournaments and Clubs inline, Search, Donate as a text link (one tap), My LCA ▾ with the count, a bordered Menu that opens the same sheet as a 400px right drawer. Event mode is one 48px strip line.
17Reflow fallback. Under 480px tall, or zoom below 300 CSS px: the bottom stack hides, the app bar stops being sticky and shows M1's bordered Menu button (WCAG 1.4.10).
18Safe area. 56px plus env(safe-area-inset-bottom); index.html gains viewport-fit=cover. The home-indicator strip stays white under the tabs.
