the club, engineered

The idea

Keep Geist and tighten the system: white or near-black surfaces, 1px borders, a faint 8-column grid, and gold saved for the main action and the current selection. The chess comes from the data: notation, clocks, board coordinates and registration counts in Geist Mono.

Best for

The site-wide base, at the lowest migration cost: today's Tailwind/shadcn tokens map straight across. Tournament pages that read like a dashboard.

Watch out for

It can look like generic software marketing. Without notation, clocks and coordinates, nothing on the page says chess or Louisiana.

Do

Set every number in Geist Mono or tabular Geist: ratings, 3½, clocks, board numbers. The data is the decoration.

Do

Spend gold once per screen: the main action or the current selection. Everything else is ink, navy and 1px lines.

Don't

Add gradient heroes, glass cards or stock "tech" illustrations. That is when it turns into SaaS marketing.

Don't

Set scores in Instrument Serif (no ½, no tabular figures) or put gold text on white (2.28:1).
