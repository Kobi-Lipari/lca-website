Recommended build

The picks

This is the lead recommendation in one breath:

  • Look: a calm Tech-Minimal base, Broadcast Night as the live event-day theme, and Bright Scholastic scoped to the scholastic pages.
  • Navigation: task-and-topic, with Donate always visible.
  • Events: one event platform covering LCA and partner events, with one checkout for a whole family and a live mode for tournament day.
  • Community: clubs that stay current on their own, and results that build into history.

Every pick links to its board.

One token system with three scopes. Build the base first; the other two switch on with a data-theme attribute.

Phases

Each ships behind flags; one workstream per branch

Phase 0 · Foundation

WS01 → WS02 → WS03. Everything else builds on the tokens, themes and navigation.

Phase 1 · Events core

WS04, WS05, WS06, plus WS13's member and parent sections. Find, decide, register.

Phase 2 · Event day

WS08's console and check-in, then WS07. Pilot at one LCA event before turning alerts on site-wide.

Phase 3 · Community

WS09, then WS10, then WS11. Where to play, what happened, how kids start.

Phase 4 · Membership, governance, admin

WS12, WS14, WS08's admin home and queue, and the rest of WS13.

Phase 5 · Extras

WS15, wallet passes, Web Push, the Grand Prix series, the festival layout and hall TV polish.

Decisions

Settled by K on October 8, 2026. The brief carries each one.

D1 · Decided

Logo and mark

The board-voted logo goes wherever there's room. The rook mark goes where space is tight: favicon, mobile header, badges.

D2 · Default

Card fee

All-in pricing: the price shown is the price paid, with no fee line. LCA absorbs Stripe's fee.

D3 · Decided

Names of minors

Full names, which congratulate kids. Initials only on a minors-only roster.

D4 · Decided

Wallet passes

In Phase 5. Start with the in-account card, a printable card and the QR.

D5 · Decided

Financial need

LCA doesn't get involved: no fee waivers and no lunch-status questions.

D6 · Decided

Who enters results

The event's TDs, with LCA admins able to step in on any event. Player reporting may come later.

D7 · Decided

Live updates

Each open page checks for changes about every 20 seconds. It's simple and free.

D8 · Decided

Text alerts

Not now, because texts cost money per message. Email and web push are free.

D9 · Decided

Player pages

None. LCA is community-focused, so results live on event pages and recaps.

D10 · Done

Club regions

All 25 clubs are assigned (brief, Appendix C). K corrects any that are off.
